Position class : 
Αυτή η κλάση έχει ως private member ένα struct (struct Cord) το οποίο έχει δύο μεταβλητές int x,y που αντιπροσωπεύουν τις συντεταγμενες
του position ενός entity στο grid/map. Επίσης έχει ένα δείκτη σε αυτό το struct για εύκολο access. 
->Οι μέθοδοι αυτής της κλάσης είναι :
-Position() ο οποίος είναι ο construstor της κλάσης.
-~Position() ο οποίος είναι ο destructor της κλάσης.
-GetPosition() η οποία επιστρέφει το private member struct Cord *cord δηλαδη ένα δείκτη στο struct με τις συντεταγμένες x,y.
-SetNewPosition() η οποία κάνει παίρνει ως όρισμα δύο int μεταβλητές οι οποίες είναι η συντεταγμένες του καινούριου position και κάνει 
update το private member struct Cord * cord. Ουσιαστικά κάνει update το position.


Grid class : 

Class members(private) : 
-Τα int x , y  τα οποία είναι το ύψος και το πλάτος του grid/map. Αυτά τα δέχεται το main πρόγραμμα ως ορίσματα γραμμής εντολών για να
δώσει αυτός που παίζει το παιχνίδι οτι διαστάσεις θέλει στον χάρτη .
-'Ενα char **grid το οποίο είναι ο δισδιάστατος πίνακας χαρακτήρων, δηλαδή ο χάρτης του παιχνιδιού.
-char Day_N_Night_Cycle το οποίο αν είναι 'N' σημαίνει οτι είναι νύχτα και αν είναι 'D' οτι είναι μέρα.
-int Max_Tree_Number είναι ο αριθμός των δέντρων που υπάρχουν στο map (αρχικοποιείται με (x*y)/40)
-int Max_Water_Number είναι ο αριθμός των water puddles που υπάρχουν στο map (αρχικοποιείται με (x*y)/40)
-int CycleCount μετρητής των frames για το πότε θα αλλάξει το Day_N_Night_Cycle.
-int EntitiesNum είναι ο αριθμός των vampires/werewolves (αρχικοποιείται με (x*y)/30)

Class methods :
-Αρχικά έχω δύο constructors έναν deafult (Grid()) που αρχικοποιεί τα x,y σε -1 και έναν με παραμέτρους (Grid(int x,int y))
ο οποίος δέχεται τις τιμές των x,y.
-Init() αυτή η συνάρτηση δεσμεύει μνήμη για το 2d πίνακα και ύστερα αρχικοποιεί κάθε θέση του πίνακα να είναι γη.
-~Grid() είναι ο destructor ο οποίος κάνει delete τη μνήμη που δεσμεύτηκε για το 2d array.
-ShowDayAndNightCycle() δείχνει πότε είναι νύχτα και πότε είναι μέρα (αυτή η συνάρτηση καλείται μέσα στην ShowGrid()).
-ShowGrid() αυτή η συνάρτηση κάνει display το grid.
-IncreaseCycleCount() αυξάνει το CycleCount.
-ChangeCycle() αλλάζει το Day_N_Night_Cycle αν το CycleCount είναι ίσο με 100 (frames) και ύστερα το κάνει ξανά μηδέν.
-CheckPlace() δέχεται δύο int τα οποία είναι συντεταγμένες στο grid και ελέγχει αν αυτή η θέση του grid είναι γη ή όχι.
-PlaceTrees() και PlaceWater() τοποθετούν σε τυχαίες κενές θέσεις του grid δέντρα και water puddles.
-PotionGenerator() τοποθετεί σε τυχαία κενή θέση του grid ένα φίλτρο.
-AccessGridPosition() δέχεται δύο int που έιναι οι συντεταγμένες μίας θέσης του grid και γυρίζει τι char βρίσκεται σε αυτή τη θέση.
-getX() και getY() γυρίζουν το x/ύψος και y/πλάτος αντίστοιχα.
-TotalEntitiesNum() γυρίζει το EntitiesNum.
-UpdateGrid() δέχεται δύο int που είναι οι συντεταγμένες μίας θέσης στο grid και ένα char και κάνει update αυτή τη συγκεκριρμένη θέση 
να είναι o χαρακτήρας που δέχθηκε.
-isPotion() δέχεται δύο int που είναι οι συντεταγμένες μίας θέσης στο grid και ελέγχει αν αυτή η θέση είναι potion.

character class : 

->Aυτή είναι η κλάση απο την οποία κληρονομούν το public μέρος της οι κλάσεις avatar , Creature (και από αυτήν κληρονομούν το public μέρος οι κλάσεις vampire και werewolf)

Class members(private) :
-char Species το οποίο θα έιναι 'v' ή 'w' αν το entity είναι vampire ή werewolf αντίστοιχα και 'V' ή 'W' στον avatar ανάλογα 
τι ομάδα υποστηρίζει.
-Position *pos ένα pointer σε object της κλάσης Position το οποίο είναι για την θέση του entity στο grid.

Class methods : 
-character() που είναι ο constructor της κλάσης.
-οι SetSpecies() και GetSpecies() οι οποίες κάνουν set και access το Species member.
-UpdatePosition() που κάνει update το position του entity μετά όταν αυτό είναι να αλλάξει(μετά από κάθε movement δηλαδή).
-StartingPoint() που τοποθετεί το entity σε μια τυχαία ελεύθερη (=land) θέση στο grid.
-GetEntityPosition() η οποία επιστρέφει το member Position *pos.
-IsInBoundary() η οποία ανάλογα με τις συντεταγμένες του position του entity ελέγχει αν είναι στο σύνορο του grid
(δέχεται ένα pointer σε object της κλάσης Grid). 

Creature class :

-> Αυτή η κλάση κληρονομεί το public μέρος της character class και είναι η κλάση η οποια περιέχει όλα τα στοιχέια που
έχουν οι vampires και οι werewolves και τις συναρτήσεις του normal movement (up,down,right,left) που και οι δύο 
entities εκτελούν (αυτή η κλάση κατασκευάστηκε κυρίως γιατί ο κώδικας του normal movement έιναι ίδιος και για τα δύο creatures για να μην γράφεται δύο φορες).

Class members(private) : 
- τρείς int μεταβλητές : heath που είναι η ζωή , power που είναι η δύναμη , defense που είναι η άμυνα του κάθε vampire/werewolf.

Class methods :  
-Creature() που είναι ο constructor της κλάσης.
-SetHealth() που κάνει update το health status του entity.
-GetHealth(),GetPower(),GetDefense() που επιστρέφουν τα members health,power,defense αντίστοιχα.
-isLegalMovement() η οποία ελέγχει αν το movement που θέλει να εκτελέσει το entity(το οποίο δέχεται ως όρισμα) είναι valid/legal.
Δηλαδή, ανάλογα το τι movement επιλέξει να κάνει το entity (up,down,right,left) ελέγχει αν η θέση στην οποία θέλει να προχωρήσει
δεν είναι εκτός ορίων και είναι land και επιστρέφει true να το movement είναι valid ή false αν δεν είναι.
Επίσης αυτή η συνάρτηση δέχεται και ενα pointer σε object του Grid class για να έχει access στο grid/map.
-Pick_Random_Movement() η οποία επιλέγει έναν αριθμό από το 1 - 4 τυχαία. Οι αριθμοί από το 1-4 αντιπροσωπεύουν τα movements.
(1 = up,2 = down,3 = right,4 = left)
-Movement() εκτελεί το movement του entity. Καλεί την Pick_Random_Movement() για να διαλέξει ένα τυχαίο movement,
και στη συνέχεια ανάλογα με το movement που διαλέξε καλέι την isLegalMovement() να ελέγξει αν μπορεί να κινηθεί σε αυτή 
τη θέση. Αν μπορεί να κινηθεί σε αυτή τη θέση τότε μετατρέπει την τωρινή του θέση σε land την επόμενη στο symbol του entity(με την UpdateGrid())
και τέλος κάνει update το position του entity.

Δηλαδή, ανάλογα το τι diagonal movement επιλέξει να κάνει o vampire (up-rigth,up-left,down-right,down-left) ελέγχει αν η θέση στην οποία θέλει να προχωρήσει

Class members(private) : 
-int Potions είναι ο αριθμός των φίλτρων που έχει ο παίκτης.
-char Team είναι η ομάδα που επιλέγει να υποστηρίξει ('V' vampires / 'W' werewolves)

Class methods : 
-avatar() , ~avatar() constructor/destructor.
-PlayerInput() πέρνει input από το πληκτρολόγιο χρησιμποιώντας getchar().

Game class : 

->Αυτή η κλάση χειρίζεται το παιχνίδι.

Class members(private) : 
-bool flag η οποία ελέγχει το while loop της GamePlay(). 'Οσο είναι true το παιχνίδι είναι ενεργό και σταματάει όταν γίνει flase.

Class methods : 
-Game() constructor.
-~Game() desstructor.
-CreateGame() η οποία δημιουργεί το παιχνίδι (κόσμος,παίχτη,οντότητες κλπ) και εκτελεί το game play.
-Start() η οποία ξεκίναει το παιχνίδι όταν ο παίχτης πατήσει 'S'.
-Resume() η οποία όταν το παιχνίδι είναι σταματημένο περιμένει πότε ο παίχτης θα πατήσει 'R' για να συνεχίσει το παιχνίδι.
-PauseGame() η οποία όταν ο παίχτης έχει πατήσει 'P' δείνει στην οθόνη όλα τα στατιστικά του παιχνιδιού.
-GamePlay() η οποία χειρίζεται το παιχνίδι. Έχει μια while loop η οποία σταματάει όταν ο παίχτης πατήσει 'Q' ή όταν χάσει μία ομάδα.
Μέσα σε αυτό το loop κάθε φορά δέχεται το input του παίχτη και εκτελεί το κατάλληλο action ανάλογα με το input. Επίσης μέσα σε αυτό το loop
εκτελούν και τα υπόλοιπα entities το movement τους και τa actions τους. 
-DisplayGameStats() η οποία παίρνει ως ορίσματα pointers σε objetcs των classes avtatar και Entities για να έχει access στον αριθμό των
ενεργών vampires/werewolves και στον αριθμό των potions που έχει ο παίχτης και τυπώνει τα stats του παιχνιδιού εκείνη τη στιγμή.
- Grid CreateWorld() η οποία αρχικοποιεί και φτιάχνει τον κόσμο(grid) και γυρίζει το object της κλάσης.
-GameOver() η οποία δέχεται ως όρισμα pointer σε object της κλάσης Entities για να έχει access στον αριθμό των ενεργών vampires/werewolves
και ελέγχει αν το μήκος των vectors είναι 0 δηλαδή αν έχει νικήσει μία ομάδα και τυπώνει ανάλογο μήνυμα και τερματίζει το παιχνίδι.

     ελέγχοντας τις διπλανές της θέσεις και επιλέγοντας την επιθυμητή ενέργεια για την καθέ μια. Έτσι, εξασφαλίζεται ότι κάθε μέλος της κάθε ομάδας θα έχει τη σειρά του.
     Ακολουθώ επόισης την λογική της EntitiesMovement όπου το ποιά ομάδα θα παίζει πρώτη ανά στιγμή θα είναι τυχαίο.
 
     Για τις κλάσεις vampire και werewolf υλοποίησα τις εξής 3 συναρτήσεις που λειτουργούν με εντελώς αντίστοιχο τρόπο και καλούνται αποκλειστικά μέσα στην συνάρτηση EntitiesAction:
        -Attack(): όταν το πλάσμα βρει πλάσμα της αντίπαλης ομάδας σε κάποια διπλανή του θέση, τσεκάρει αν είναι τουλάχιστον όσο δυνατό όσο εκείνο ώστε να επιχειρήσει να του επιτεθεί.
         Η μείωση ζωής του αμυνόμενου γίνεται σύμφωνα με τις οδηγίες της εκφώνησης.
        -Dodge(): η συνάρτηση αυτή λειτουργεί αρκετά απλά, καλείται μόνο όταν ένα πλάσμα εντοπίσει εχθρό σε κάποια διπλανή του θέση και δεν μπορεί να του επιτεθεί,
         οπότε βρίσκει την πρώτη διαθέσιμη ελεύθερη θέση (γη) και μετακινείται σε αυτή σε μια προσπάθεια να απομακρυνθεί από τον εχθρό. Θα μπορούσα εδώ να προσθέσω
         κι άλλο κώδικα ώστε να κάνω το πλάσμα να επιλέγει καλύτερα σε ποιά θέση να κατευθυνθεί αλλά κάτι τέτοιο θα έκανε το παιχνίδι ακόμα πιο περίπλοκο ενώ ήδη,
         όπως αναφέραμε, υπάρχει δυσκολία στο να τερματίσει.
        -Heal(): το πλάσμα ελέγχει αν υπάρχει συμπαίκτης του σε διπλανή θέση που έχει δεχτεί επίθεση και αν το ίδιο έχει τουλάχιστον ένα γιατρικό φίλτρο, 
         επιλέγει τυχαία εάν θα το γιατρέψει.


Χώρησα την εργασία σε:
    ένα αρχείο cpp που περιέχει την main από την οποία δημιουργείται και ξεκινάει το παιχνίδι, 
    ένα header file και ενα cpp file για κάθε κατηγορία κλάσεων με τα declarations και τα definitions τους αντίστοιχα,
    το βοηθητικό constants.h που ορίζει τις σταθερές που χρησιμοποιήθηκαν στον κώδικα μας.
